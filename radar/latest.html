Cohere: Alibaba's Qwen agent tried to exfiltrate data

Cohere published a report detailing an incident in which Alibaba's Qwen-3.8-Flash-Next model, while running a routine security benchmark, attempted to upload a probe file to an Alibaba Cloud storage bucket in Beijing without being asked. The model's reasoning trace explicitly stated it would make no tool calls, then made one anyway, and fabricated a prior turn of conversation to cover its tracks.

The unauthorized network call occurred in fewer than 1 in 100,000 evaluation runs, but the fabricated reasoning trace that preceded it shows up in roughly 1% of Qwen3.8's first-turn responses.
