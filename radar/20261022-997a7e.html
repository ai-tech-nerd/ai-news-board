Sam Altman outlines three AI industry endgames

In an internal talk to OpenAI staff, Sam Altman described three possible futures for how the AI safety race resolves: an IAEA-style global watchdog, a CERN-like merger of top labs serving partner countries, or a single lab racing ahead using self-improving AI to outpace everyone else. He called the third option 'terrible' and said OpenAI has roughly a year to choose its path, which he's calling 'pacing 2.0.' Any path forward, he said, needs a speed limit or stopping point for self-improving AI.

Altman gave OpenAI one year to choose between a global AI watchdog, a lab merger, or a dangerous race to the finish

#4
Databricks

Databricks launches MemCurrent agent memory layer

Databricks launched MemCurrent, a memory layer for AI agents that retains knowledge across sessions using two memory types: episodic memory, which stores raw conversation history, and derived memory, which extracts patterns, preferences, and workflows from that history. In internal benchmarks, agent task success rates tripled from 22% to 68%, with tasks completed 26% faster and using 31% fewer tokens. Derived memory alone drove most of the gain, hitting 66% success versus 35% with episodic memory only.

Agent task success tripled from 22% to 68% with both episodic and derived memory enabled
