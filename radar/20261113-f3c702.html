#2
Google

Google launches Gemini Decisions API for agents

Google released the Gemini Decisions API, giving developers access to a model built for rapid, structured decision-making rather than generating text. It handles yes/no questions, multiple choice with up to 255 options, and rubric-based scoring, returning results in as little as 150 milliseconds. The model costs $0.10 per million input tokens with output tokens free, matching OpenAI's pricing and competing directly with TypeSafe's Jev.

Gemini Decisions API returns outputs in as little as 150ms, compared to traditional LLMs that can take up to 329 seconds.
